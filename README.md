# 💾 Proyecto SQL – Base de Datos Empresarial

## 📌 Descripción

Este proyecto consiste en la creación y gestión de una base de datos utilizando SQL, simulando un entorno empresarial con empleados, áreas y salarios.

---

## 🧩 Tecnologías utilizadas

* SQL
* SQLite
* DataGrip

---

## ⚙️ Requisitos

Para ejecutar este proyecto es necesario contar con:

* Un gestor de bases de datos como DataGrip o cualquier herramienta compatible con SQL
* Soporte para SQLite o un motor de base de datos similar

---

## ⚙️ Funcionalidades

* Creación de tablas
* Inserción de datos
* Consultas (SELECT)
* Filtros (WHERE, LIKE)
* Modificación de datos (UPDATE)
* Eliminación de registros (DELETE)
* Análisis de datos (COUNT, GROUP BY, AVG)

---

## 🧠 Aprendizaje

Se aprendió a gestionar bases de datos, realizar consultas y analizar información mediante SQL.
